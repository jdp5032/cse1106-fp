## PROJECT OUTLINE ##

-- Goal -- 

The goal of this project is to successfully form a connection between software and hardware.

# Stage 1 

The first stage was writing the program to be sure that it works as intended. After numerous test cases, it was confirmed to be working as intended and we were able to move onto Stage 2.

# Stage 2

The second stage was connecting the circuit with the raspberry pi and assuring ourselves that our program would be able to connect to the circuit and be able to control it. 

# Stage 3

The third stage was connecting our program with the raspberry Pi and successfully controlling the circuit without any hiccups. Our primary focus was the organization and accessibility of our program and circuit.
