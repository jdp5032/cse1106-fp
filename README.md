# TEMPERATURE ALARM SYSTEM

This point of this program is to recieve input and activate a light on a circuit board depending if there are warnings or not. 

---

## Prerequisites & Dependencies 
 * Raspberry Pi
 * Circuit Board
 * GCC

---

## Installed & Setup

The program itself is fairly simple and self explanatory, but if you want to safe the readings to a file, the program does that for you! All you have to do is when you compile the program in your terminal is to give a command line of the file that you want to save your data into.
